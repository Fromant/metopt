# Формула связи числа итераций с требуемой точностью

## Поиск методом золотого сечения

### Теория
В методе золотого сечения интервал уменьшается на постоянный коэффициент на каждой итерации.
Золотое сечение φ = (1 + √5)/2 ≈ 1.618
Мы используем ρ = (φ - 1) = (√5 - 1)/2 ≈ 0.618

После каждой итерации размер интервала умножается на ρ.
Начиная с интервала [a₀, b₀], после n итераций размер интервала будет:
|bₙ - aₙ| = ρⁿ|b₀ - a₀|

### Формула для необходимого числа итераций
Чтобы достичь точности ε (т.е. |bₙ - aₙ| ≤ ε), необходимо:
ρⁿ|b₀ - a₀| ≤ ε

Принимая логарифмы:
n × ln(ρ) ≤ ln(ε/|b₀ - a₀|)
Поскольку ln(ρ) < 0, деление на ln(ρ) меняет знак неравенства:
n ≥ ln(ε/|b₀ - a₀|) / ln(ρ)

Поскольку ρ = (√5 - 1)/2 ≈ 0.618, ln(ρ) ≈ -0.4812
Таким образом: n ≥ ln(ε/|b₀ - a₀|) / (-0.4812) = -ln(ε/|b₀ - a₀|) / 0.4812

### Окончательная формула
n ≥ ln(|b₀ - a₀| / ε) / ln(1/ρ) = ln(|b₀ - a₀| / ε) / ln((√5 + 1)/2)

Для нашей функции f(x) = x² - 2x - 2cos(x) на [0.5, 1]:
- |b₀ - a₀| = 0.5
- Для ε = 0.1: n ≥ ln(0.5/0.1) / ln(1.618) ≈ ln(5) / 0.481 ≈ 3.32
- Для ε = 0.01: n ≥ ln(0.5/0.01) / ln(1.618) ≈ ln(50) / 0.481 ≈ 8.19  
- Для ε = 0.001: n ≥ ln(0.5/0.001) / ln(1.618) ≈ ln(500) / 0.481 ≈ 13.07

## Равномерный поиск

### Теория
Для равномерного поиска с k точками на итерацию интервал обычно уменьшается до доли предыдущего интервала на основе распределения точек вокруг минимума.

Если мы используем k точек на итерацию и фокусируемся на подинтервале, который составляет 2/(k-1) от исходного интервала вокруг точки минимума, то после n итераций:
|bₙ - aₙ| = (2/(k-1))ⁿ|b₀ - a₀|

Однако более простой подход состоит в том, чтобы учитывать, что с k точками мы делим интервал на k-1 сегментов, поэтому результирующая неопределенность составляет примерно |b - a|/(k-1).

Для фиксированного общего числа вычислений функций N, если мы разбиваем на раунды:
- С k точками на раунд, нам нужно примерно log_{k-1}(|b₀ - a₀|/ε) раундов
- Общее число вычислений функций: N ≈ k + (раунды - 1) * k (для первого раунда мы вычисляем k точек, затем k-2 для последующих раундов, так как повторно используем 2 точки)
