# Алгоритм равномерного поиска

## Обзор
Равномерный поиск (также известный как равномерное деление или решетчатый поиск) — это метод нахождения минимума функции путем вычисления её значений в равномерно расположенных точках на интервале поиска. Метод систематически делит интервал на равные сегменты и определяет сегмент, содержащий минимум.

## Математическая основа
Для заданного интервала [a, b] и n точек вычисления, алгоритм вычисляет значение функции в:
- xᵢ = a + i × h, где h = (b - a) / (n - 1), для i = 0, 1, ..., n-1

## Шаги алгоритма
1. Инициализировать интервал [a, b] и допустимую погрешность ε
2. Определить количество начальных точек n на основе допуска
3. Рассчитать размер шага: h = (b - a) / (n - 1)
4. Вычислить функцию во всех n точках: f(xᵢ) для i = 0, 1, ..., n-1
5. Найти точку xₘ с минимальным значением функции
6. Уточнить поиск вокруг xₘ, создав новый меньший интервал
7. Повторять шаги 2-6 до тех пор, пока ширина интервала ≤ ε
8. Вернуть точку с найденным минимальным значением функции

## Адаптивная версия
Более эффективный подход — адаптивный равномерный поиск:
1. Начать с интервала [a, b] и начального количества точек
2. Вычислить функцию в равномерных точках
3. Определить точку с минимальным значением
4. Создать новый интервал, центрированный в точке минимума, с уменьшенной шириной
5. Повторять до достижения требуемой точности

## Скорость сходимости
- Для n точек за итерацию, скорость сокращения интервала зависит от стратегии уточнения
- Обычно медленнее, чем поиск методом золотого сечения при одинаковом количестве вычислений функции
- Количество необходимых итераций зависит от начального интервала и требуемой точности

## Преимущества
- Простота реализации и понимания
- Может обнаруживать несколько локальных минимумов
- Нет предположений о непрерывности функции, кроме унимодальности
- Возможность параллельных вычислений функции

## Недостатки
- Требует больше вычислений функции за итерацию, чем метод золотого сечения
- Менее эффективная скорость сходимости
- Производительность сильно зависит от выбранного количества точек
