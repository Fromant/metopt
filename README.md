# Методы оптимизации СПБПУ Родионова

## Lab 1 - Линейное программирование

### Возможности:

- Читалка из файла и из консоли задачи ЛП
- Вывод в консоль форму постановки
- Приведение к любой форме постановки (канон/симметр/общая)
- Построение двойственной задачи
- Печать задачи в консоль (в той форме к которой привели)
- Simplex solver
- Enum solver
- В канонической форме приводить все rhs к неотрицательным
- Считать погрешности, выводить в нормальной форме

## Lab 2 - Транспортная задача

### Возможности:

- Читалка транспортной задачи из файла и консоли
- Проверка корректности и сбалансированности
- Балансировка задачи (добавление фиктивного поставщика/потребителя)
- **Поддержка штрафов за недопоставку** - для каждого потребителя можно задать штраф за неудовлетворённый спрос
- Метод северо-западного угла для построения начального плана
- **Метод MODI (потенциалов)** для нахождения оптимального плана
- **Публичные методы для демонстрации цикла пересчёта:**
  - `findCycle()` - поиск цикла для вводимой в базис клетки
  - `applyCycle()` - применение цикла к плану
  - `printCycle()` - вывод цикла в консоль
  - `printPotentials()` - вывод потенциалов в консоль
  - `printDeltas()` - вывод оценок свободных клеток в консоль
- Преобразование транспортной задачи в задачу ЛП
- Согласованность с SimplexSolver (проверка через LP-формулировку)

## Использование

### Линейное программирование

Чтобы читать из файла запустите с аргументом:
```bash
./lp_main filename.txt
```

Чтобы читать из консоли - запускайте без аргумента:
```bash
./lp_main
```

### Транспортная задача

Транспортная задача решается через тот же интерфейс (файл задачи определяет тип). Для транспортных задач используйте:

```bash
./lp_main transport_task.txt
```

## Формат файлов

### Линейное программирование

```
min/max
num_variables
c1 c2 c3 c4 c5
num_constraints
a11 a12 a13 a14 a15 <= b1
...
>=0 <=0 free free free
```

- `min/max` - тип оптимизации
- `num_variables` - количество переменных
- `c1 c2 ...` - коэффициенты целевой функции
- `num_constraints` - количество ограничений
- `a11 a12 ...` - коэффициенты матрицы ограничений
- `<=`, `>=`, `=` - тип ограничения
- `b` - правая часть ограничения
- `>=0`, `<=0`, `free` - ограничения на знак переменных

### Транспортная задача (базовая)

```
m n
a1 a2 ... am
b1 b2 ... bn
c11 c12 ... c1n
c21 c22 ... c2n
...
cm1 cm2 ... cmn
```

- `m` - количество поставщиков
- `n` - количество потребителей
- `a1 ... am` - запасы поставщиков
- `b1 ... bn` - потребности потребителей
- `cij` - матрица стоимостей (m × n)

### Транспортная задача (с штрафами)

```
m n
a1 a2 ... am
b1 b2 ... bn
c11 c12 ... c1n
c21 c22 ... c2n
...
cm1 cm2 ... cmn
p1 p2 ... pn
```

- `p1 ... pn` - штрафы за недопоставку для каждого потребителя (опционально)
- Штрафы используются при балансировке: если спрос превышает предложение, фиктивный поставщик получает стоимость равную штрафу каждого потребителя

## Тесты

Проект включает набор тестов:

```bash
cd build
cmake ..
make
./tests/lp_test
```

### Доступные тесты:

- **SimplexSolverTest** - тесты симплекс-метода
- **EnumSolverTest** - тесты переборного метода
- **TransportIntegrationTest** - интеграционные тесты транспортной задачи
- **TransportUnitTest** - юнит-тесты транспортной задачи
- **MODISolverCycleTest** - тесты публичных методов демонстрации цикла
