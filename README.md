# Usage

Чтобы читать из файла запустите с аргументом `./metopt filename.txt`.

Чтобы читать из консоли - запускайте без аргумента. Будет интерактивная шоу-программа в консоли

# Формат фалйа
Формат задачи ЛП:

Целевая функция:
`c^T * x -> min`

Ограничения:
`A[i]x - b >=0` или `A[i]x - b = 0` - где `i` - номер строки матрицы

Ограничения на знак:
`x[i] >= 0` `x[i] <= 0`

Формат файла:
```text
min/max
num_variables
c1 c2 c3 c4 c5
num_constraints
a11 a12 a13 a14 a15 <= b1
...

>=0 <=0 free free free
```

`num_constraints` - количество ограничений
`num_variables` - количество переменных
`a11 a12 a13 a14 a15` - коэффициенты матрицы ограничений

`>=0`, `<=0`, `free` - ограничения на знак переменной. Обязательно для каждой переменной
